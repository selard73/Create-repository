1. Unzip Meshy zip to `squirrels/<id>/src/` (check the id is free).
2. Blender = `%LOCALAPPDATA%\Microsoft\WindowsApps\blender-launcher.exe` (returns immediately; poll the log). `prep_premerge.py <in> <mid.fbx> 280000 <log>`, then again to 7000, then `prep_squirrel.py <m7k.fbx> <dir> <id> <texture.png> 7400 2.4 0` -> look at ref_front.png.

## Gotchas learned (keep)
- computer-use `type`: keep chunks <= 15 chars. Before typing a long line, type one chunk and zoom on the command bar to confirm it landed (zoom may lag one frame; screenshot if unsure).
- **Play tests**: the command bar sometimes does NOT take focus and keys go into the game (WASD moved her character). Move characters from the **Server** tab (`game.Players:GetPlayers()[1].Character:PivotTo(...)`); for views use the Client tab with `workspace.CurrentCamera.CameraType=Scriptable` after confirming focus. Edits made during a play test are lost - stop first (wait ~30 s for teardown).
- A Downloads File Explorer window overlaps Studio's top-left; if a click lands on it, click Studio's title bar at (1200,68). Never type into Explorer. Snipping Tool in front blocks all clicks - ask her to close it.
- Python heredocs mangle `\n` inside Lua strings: write Lua with the Write tool or build parts in files. A trailing `--` comment added by string replace can cut off the rest of a Lua line (happened once).
- One OBJ with several objects imports as ONE merged mesh with one texture; upload separate images as separate OBJ files.
- Studio "grid marks" on everything = Studio low on graphics memory (hours of imports/terrain); not in the place - restart Studio.
- Flat painted backdrop walls look terrible from high viewpoints (base + ends show) - never again; hide distant content client-side instead.
- Big meshes far away: set RenderFidelity Precise or Automatic LOD tears holes.
- Terrain passes: restore from backup and rebuild in one pass rather than stacking passes; average heights across neighbouring columns to avoid slots; never let a slope run past the edit area's edge.
