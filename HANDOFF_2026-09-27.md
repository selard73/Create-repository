## How a change gets into the game
Every builder is a Lua file that `return function(opts) ... end`. It rebuilds its own piece of the workspace, and it is safe to run again.

1. **Make a runner.** A runner generator (`tools/gen_*_runner.py`) wraps a builder into one command-bar script, `run_*.lua`, with a unique `vN` tag on line 1.
   - The generators still write into Claude's old temp folder. Change the output path at the bottom of each one first.
2. **Run it in Studio**, in **Edit mode** (not Play). Open View > Command Bar and paste the whole script. Check that line 1 shows the new `vN` tag, then run it.
3. **Read the result.** Results appear as warnings starting with `QQ` in the Output window. They're also written to `%LOCALAPPDATA%\Roblox\logs\*Studio*.log`.
4. **Test in Play.** Paste these helper scripts into the command bar while in the **Server** view:
   - `tools/t29_setup_srv.lua`: opens the gates, gives you the glider and 1500 acorns, and puts you at the top.
   - `tools/t27_srv.lua`: a flight where you don't steer.
   - `tools/t28_srv.lua`: a ride in the basket.
   - A fresh Play session has the Château **locked**. The test scripts unlock it first by setting `Found_forest` / `Found_village`.
5. **Check before publishing.** Run `tools/prepublish9.lua` in Edit mode. Expect `QQ PREPUB9 - 54/54 true` and `strays: none`. The 13 unanchored tractor parts it lists are normal.

## Publishing (only when Shannon says so)
1. Stop Play, so Studio is back in Edit mode.
2. Go to File > Experience Settings > Security and turn **"Enable Studio Access to API Services"** ON, then Save.
   - If "Could not save experience settings" appears, that's a hiccup on Roblox's side. Press Save again.
3. Go to File > Publish to Roblox. The Output should say `Published new changes in "1001 Squirrels" to Roblox.`
4. Go back to File > Experience Settings > Security, turn the setting **OFF** and Save. Reopen the dialog to check it stayed off.
